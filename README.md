# oth-guides

Гайды по Over the Hill для канала «Толян, погоди!» – интерактивные страницы, которые открываются в браузере
и на эфире.

| Гайд | Папка | Что внутри |
|---|---|---|
| Фотоохота в Канаде | [`canada-animals/`](canada-animals/) | Маршрут по всем 16 животным Канады: Изумрудное озеро и Гимли-Ридж, 14 точек по порядку, время суток, погода, запасные точки, ачивки |

## Сайт

https://letulip.github.io/oth-guides/ – открывается всем, без входа. GitHub Pages публикует ветку `main` как есть
(Settings → Pages → Deploy from a branch: `main`, `/ (root)`), корень сайта ведёт на первый гайд. Файл `.nojekyll`
отключает сборку Jekyll, страницы отдаются как лежат.

Локально – из корня репозитория:

```bash
python3 -m http.server 8131
```

и http://localhost:8131 (через `file://` подложки карт не загрузятся).

## Языки

Страницы на русском и английском, переключатель RU / EN – в правом верхнем углу. Язык выбирается так: `?lang=en`
или `?lang=ru` в ссылке, иначе прошлый выбор в этом браузере, иначе язык браузера (русский, украинский, белорусский,
казахский – русская версия, остальные – английская). Ссылка на английскую версию:
https://letulip.github.io/oth-guides/?lang=en
